# Cost to Build a House in Arkansas — blog page

Built from the content brief "Cost to Build a House in Arkansas" (HSD content sprint, September 2026), with the same layout and components as the Alabama and Alaska posts (shell copied from `blog/cost-to-build-a-house-in-alaska/`). Lives in `blog/`, so links to the rest of the site start `../../`.
Plain HTML, CSS and JavaScript. No build step and no dependencies.

## Sections

1. Hero: "Blog · Arkansas cost guide" eyebrow, intro (second paragraph behind Read More), two buttons, and the navy house card (builder grade $150–$220 and custom $220–$300+ per sq ft).
2. Trust logos and reviews (shared with the other pages).
3. Average cost: lead + 2 rate tiles ($140–$152 per sq ft; $280,000–$304,000 for 2,000 sq ft).
4. How to estimate: 10 steps, the information-needed question with 8 cards, accordion (estimating without plans).
5. Estimating services: lead, the estimate-contents question with 8 cards, accordion (sitework and subcontractor costs).
6. Cost calculator: lead.
7. Cost per square foot: lead, 3 rate tiles ($140–$152; 1,500 sq ft = $210,000; 2,500 sq ft = $380,000), the factors question with 7 cards, accordion (land costs).
8. 3,000 sq ft homes: lead, 2 rate tiles (builder grade $450,000–$660,000; custom $660,000–$900,000), accordion (fixed cost).
9. Trade-by-trade costs: 12 cards (bullet summary shows; Read More reveals the numbered paragraph).
10. Cost factors: 4 tabs (main factors, materials and labor, lot and location with site-prep and utility tiles, home design), each follow-up question in an accordion.
11. Additional costs: 7 cards, then the closing "What Determines the Final Cost" question.
