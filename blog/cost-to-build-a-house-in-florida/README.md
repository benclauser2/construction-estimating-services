# Cost to Build a House in Florida — blog page

Built from the content brief "Cost to Build a House in Florida" (HSD content sprint, September 2026), with the same layout and components as the other blog posts (shell copied from `blog/cost-to-build-a-house-in-arkansas/`; the brief follows the same template as the California post). Lives in `blog/`, so links to the rest of the site start `../../`.
Plain HTML, CSS and JavaScript. No build step and no dependencies.

## Sections

1. Hero: "Blog · Florida cost guide" eyebrow, intro (second paragraph behind Read More), two buttons, and the navy house card (statewide $120–$300 and standard build $150–$230 per sq ft).
2. Trust logos and reviews (shared with the other pages).
3. Average cost: lead + 2 tiles ($240,000–$600,000; ≈ $350,000 for 2,000 sq ft at $175).
4. How to estimate: 9 steps, the information-needed question with 8 cards, accordion (estimating without plans).
5. Estimating services: lead, the estimate-contents question with 8 cards, accordion (sitework and subcontractor costs).
6. Cost calculator: lead, accordion (final building cost).
7. Cost per square foot: lead, 2 tiles ($120–$300; $150–$230 standard build), the factors question with 7 cards, accordion (land costs).
8. 3,000 sq ft homes: lead, 2 tiles (lower end $360,000; upper end $900,000), accordion (fixed cost).
9. Trade-by-trade costs: 12 cards (bullet summary shows; Read More reveals the numbered paragraph).
10. Cost factors: 4 tabs (main factors, materials and labor, lot and location, home design), each follow-up question in an accordion.
11. Additional costs: 7 cards, then the closing "What Determines the Final Cost" question.
