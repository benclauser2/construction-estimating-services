# Cost to Build a House in Colorado — blog page

Built from the content brief "Cost to Build a House in Colorado" (HSD content sprint, September 2026), with the same layout and components as the other blog posts (shell copied from `blog/cost-to-build-a-house-in-arkansas/`). Lives in `blog/`, so links to the rest of the site start `../../`.
Plain HTML, CSS and JavaScript. No build step and no dependencies.

## Sections

1. Hero: "Blog · Colorado cost guide" eyebrow, intro (second paragraph behind Read More), two buttons, and the navy house card (basic $200–$300 and custom $300–$500 per sq ft).
2. Trust logos and reviews (shared with the other pages).
3. Average cost: lead + 2 rate tiles (basic $300,000–$750,000; custom $450,000–$1,500,000).
4. How to estimate: 8 steps, the information-needed question with 8 cards, accordion (estimating without plans).
5. Estimating services: lead, the estimate-contents question with 8 cards, accordion (sitework and subcontractor costs).
6. Cost calculator: lead, accordion (final building cost).
7. Cost per square foot: lead, 3 rate tiles (basic $200–$300; custom $300–$500; 2,000 sq ft basic at $250 = $500,000), the factors question with 7 cards, accordion (land costs).
8. 3,000 sq ft homes: lead, 2 rate tiles (basic $600,000–$900,000; custom $900,000–$1,500,000), accordion (fixed cost).
9. Trade-by-trade costs: 12 cards (bullet summary shows; Read More reveals the numbered paragraph).
10. Cost factors: 4 tabs (main factors, materials and labor, lot and location with grading/excavation/utility tiles, home design), each follow-up question in an accordion.
11. Additional costs: 6 cards, then the closing "What Determines the Final Cost" question.
